PangoLock

One click to hide. One more to encrypt. Your folder disappears from Finder and every other app.

Two levels of armor

Hide when it's private. Lock when it's secret.

Hidden

Hide

Removes the item from Finder, strips all POSIX permissions (chmod 000) and drops a Spotlight skip marker, so video players, media scanners and search can't reach it. Show restores everything.

Strong against ordinary apps. Not encryption.

Encrypted

Lock

Archives the folder, encrypts it with AES‑256‑GCM into a managed .plock blob, decrypts and verifies the result, and only then removes the plaintext. Nothing can find or read it until you unlock.

The real defense. Use it for anything sensitive.

Security is the product

From password to ciphertext, step by step.

  1. 01

    Your password

    Typed, used, wiped from memory with memset_s. Never written anywhere.

  2. 02

    PBKDF2‑HMAC‑SHA256

    210,000 iterations over a random 16‑byte salt derive the master key.

  3. 03

    HKDF per item

    Each folder gets its own independent key, or one from its own folder password.

  4. 04

    AES‑256‑GCM

    nonce ‖ ciphertext ‖ tag, fresh nonce every time. Tampering fails to open.

  5. 05

    Verify, then delete

    The blob is decrypted and checked before the plaintext is ever removed.

Build it yourself in a minute.

Universal binary for Apple Silicon and Intel.

zsh
git clone https://github.com/suriya4code/PangoLock.git
cd PangoLock
xcodebuild build -project PangoLock.xcodeproj -scheme PangoLock \
  -configuration Debug -destination 'platform=macOS' \
  CODE_SIGNING_ALLOWED=NO -derivedDataPath build
open build/Build/Products/Debug/PangoLock.app
run the tests
xcodebuild test -project PangoLock.xcodeproj -scheme PangoLock \
  -destination 'platform=macOS' CODE_SIGNING_ALLOWED=NO -derivedDataPath build
